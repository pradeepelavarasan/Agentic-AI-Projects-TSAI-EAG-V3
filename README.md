## Featured Projects

### 1. [Computer Use Agent (Session 10)](https://github.com/pradeepelavarasan/computer-use-agent)

A multi-agent native desktop automation platform for macOS. Extends the concurrent Directed Acyclic Graph (DAG) orchestrator with a **Computer** skill that drives live desktop applications through a 5-layer cascade — **AX Extract (Read-Only) → AppleScript → Deterministic Hotkeys → AX Tree + Text LLM → Vision Set-of-Marks (SoM)** — backed by a strict **Scan → Act → Verify** loop.

- 🔗 **Repository:** [github.com/pradeepelavarasan/computer-use-agent](https://github.com/pradeepelavarasan/computer-use-agent)

### 2. [Browser Agent for Shopping (Session 09)](https://github.com/pradeepelavarasan/Browser-Agent-for-Shopping)

A multi-agent e-commerce browser automation and product analysis platform powered by Playwright. Combines an 8-stage concurrent shopping DAG (`Planner`, `Browser`, `Product Shortlister`, `Critic`, `Product Analyst`, `Product Recommendation`, `Formatter`) with a 4-layer browser cascade — **Static HTML (Trafilatura) → Deterministic Selectors → Accessibility (A11y) Tree → Set-of-Marks (SoM) Vision**.

- 🔗 **Repository:** [github.com/pradeepelavarasan/Browser-Agent-for-Shopping](https://github.com/pradeepelavarasan/Browser-Agent-for-Shopping)
