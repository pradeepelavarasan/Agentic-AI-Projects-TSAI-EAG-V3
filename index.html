Session 10 · Native Desktop Control

DAG-Based Architecture

Concurrent Graph Orchestration with Native OS Control

Inherits the concurrent DAG orchestrator (`flow.py`) from the Browser Agent and introduces the Computer skill node (`computer_use_agent/server.py`) as the primary execution unit for native macOS tasks. Every interactive step runs a strict Scan → Act → Verify cycle to confirm UI state mutations before proceeding.

1. Planner → 2. Computer (5-Layer Cascade) → 3. Critic → 4. Browser (Optional) → 5. Formatter

  • Target OS macOS Native GUI

Five-Layer Computer Cascade

Dynamically escalates from zero-LLM accessibility reads and AppleScript data models to full Vision Set-of-Marks reasoning.

Layer 01Read-Only
AX Extract

Passive read of the macOS Accessibility tree via `cua-driver get_window_state`. Stops immediately if a scan satisfies the goal.

Cost: Negligible · 0 LLM calls
Layer 02Data Model
AppleScript

Generates a targeted AppleScript command talking directly to scriptable apps (Word, Notes, Mail, Calendar, Finder, Safari).

Cost: Low · 1 LLM call
Layer 03System Events
Deterministic Hotkeys

Executes planner-supplied keystroke sequences (`cmd+n`, `Return`, text typing) directly via macOS System Events.

Cost: Negligible · 0 LLM calls
Layer 04Interactive AX
AX Tree + Text LLM

Presents live OS Accessibility elements to a text LLM across up to 12 Scan → Act → Verify turns for standard native apps.

Cost: Moderate · Text LLM
Layer 05Visual Fallback
Vision Set-of-Marks

Screenshots the window, overlays numbered bounding boxes, and drives opaque/Electron apps (like Telegram) via Vision LLM.

Cost: High · Vision LLM

Four-Layer Browser Automation Cascade

Escalates from static HTML extraction to full Set-of-Marks visual reasoning based on page responsiveness and layout complexity.

Layer 01Static HTTP
HTML Extraction

Static HTTP GET using `httpx` parsed via `trafilatura`. Ideal for read-only product pages and fast link harvesting.

Cost: Negligible · 0 LLM calls
Layer 02aPlaywright
Deterministic Selectors

Programmatic CSS/XPath selectors supplied by the planner to click or fill known elements without LLM reasoning.

Cost: Negligible
Layer 02bSemantic DOM
A11y Tree Driver

Extracts the active Accessibility Tree (`[id]<tag role>name</tag>`) for text-only LLM navigation of checkboxes and links.

Cost: Moderate · Text LLM
Layer 03Visual DOM
Set-of-Marks (SoM) Vision

Overlays numbered interactive boxes onto live Playwright screenshots with a text legend for complex, dynamic layouts.

Cost: High · Vision LLM
