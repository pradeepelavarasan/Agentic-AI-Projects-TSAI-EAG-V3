Session 10 Native macOS Desktop Control

Computer Use Agent

A multi-agent native desktop automation platform for macOS built to test and demonstrate GUI control techniques — AppleScript scripting, macOS Accessibility tree navigation, deterministic hotkeys, and vision-based Set-of-Marks interaction — inside live desktop applications.

This project extends the Directed Acyclic Graph (DAG) multi-agent orchestrator from the Browser Agent with a dedicated Computer skill node (`Planner → Computer → Critic → Browser (Optional) → Formatter`). Every interactive turn enforces a strict Scan → Act → Verify cycle so the agent confirms UI state changes before proceeding.

Session 10 — Five-Layer macOS Native Desktop Automation Cascade Open full README on GitHub ↗

Five-Layer Computer Cascade

Before any layer runs, a zero-cost AppleScript pre-flight brings the target application to the foreground. The skill then escalates from the fastest read-only check to full visual reasoning.

Layer 01
AX Extract (Read-Only)

Passive read of the macOS Accessibility tree via `cua-driver get_window_state`. Stops immediately if a scan satisfies the goal.

Cost: Negligible (0 LLM calls)
Layer 02
AppleScript Dictionary

Generates a targeted AppleScript command speaking directly to scriptable apps' data models (Word, Notes, Mail, Finder, Safari).

Cost: Low (1 LLM call)
Layer 03
Deterministic Hotkeys

Executes pre-computed keystroke sequences (`cmd+n`, `Return`, text entry) directly via System Events with Scan-Act-Verify checks.

Cost: Negligible (0 LLM calls)
Layer 04
AX Tree + Text LLM

Presents live OS Accessibility elements to a text LLM across up to 12 Scan → Act → Verify turns for standard native macOS apps.

Cost: Moderate (Text LLM)
Layer 05
Vision Set-of-Marks

Overlays numbered bounding boxes onto live screenshots for opaque or Electron apps (e.g., Telegram) lacking exposed AX trees.

Cost: High (Vision LLM)

Four-Layer Browser Automation Cascade

The Browser Agent dynamically escalates from static HTML extraction to full Set-of-Marks visual reasoning depending on task complexity and page responsiveness.

Layer 01
HTML Extraction (Trafilatura)

Static HTTP GET via `httpx` parsed with `trafilatura`. Ideal for read-only product detail extraction and fast link harvesting.

Cost: Negligible (0 LLM calls)
Layer 02a
Deterministic Selectors

Programmatic Playwright selectors supplied by the planner to click or fill known elements without invoking LLM reasoning.

Cost: Negligible
Layer 02b
Accessibility (A11y) Tree

Extracts the browser's active Accessibility Tree (`[id]<tag role>name</tag>`) so a text LLM can drive semantic checkboxes, inputs, and links.

Cost: Moderate (Text LLM)
Layer 03
Set-of-Marks (SoM) Vision

Captures a live Playwright screenshot overlaid with numbered interactive bounding boxes and a text legend for complex e-commerce layouts.

Cost: High (Vision LLM)
